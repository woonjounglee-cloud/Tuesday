## 📋 기능

### 📂 파일 업로드
- **ETF/주식 버튼**: 헤더의 ETF/주식 버튼으로 파일 업로드
- **자동 데이터 반영**: `data_XXXX_YYYYDDMM.xlsx` 형식 파일 처리
- **종목명/종가 자동 입력**: ROI 테이블에 자동으로 종목명과 종가 채우기
- **날짜 자동 추출**: 파일명에서 날짜 추출하여 Balance에 자동 입력

### 📈 ROI (수익률)
- 종목별 투자 정보 관리
- 평가금 자동 계산 (수량 × 종가)
- 수익률 자동 계산 ((평가금 - 초기투자금) / 초기투자금 × 100)
- 실시간 편집 가능
- 행 추가/삭제 기능
- 마이너스 수익률 빨간색 표시

### 💰 Balance (잔고)
- 월별 투자 현황 추적
- 투자원금, 추가납입, 잔고 관리
- ROI 데이터 기반 자동 계산
  - 투자원금 = ROI 초기투자금 총합
  - 잔고 = ROI 평가금 총합
  - 수익률 = (잔고 - 투자원금) / 투자원금 × 100
- 시각적 차트로 잔고 추이 확인
- 기타 칸 넓게 표시

### 🎯 Portfolio (포트폴리오)
- 자산 배분 설정 (자산군, 구분 입력)
- 세팅비중 설정 (소수점 1자리, % 표기)
- Rebalancing 버튼으로 현재비중 및 빨강매수 자동 계산
  - 현재비중 = ROI 평가금 / ROI 평가금 총합
  - 빨강매수 = (세팅비중 - 현재비중) × ROI 평가금 총합
- 양수는 빨간색, 음수는 괄호 표기
- 세팅비중 합계 100% 검증

### 📁 다중 DB 지원
- **Home - IRP**: 집 IRP 계좌
- **WJ - ISA**: WJ ISA 계좌 (준비 중)
- **WJ - 주식**: WJ 주식 계좌 (준비 중)
- **MG - IRP**: MG IRP 계좌 (준비 중)
- **MG - 개인연금**: MG 개인연금 계좌 (준비 중)

## 💡 사용 방법

### 기본 사용법
1. **계정 선택**: 상단 탭에서 관리할 계정 선택 (Home-IRP, WJ-ISA, 등)
2. **데이터 편집**: 테이블에서 직접 값 입력
3. **행 추가/삭제**: ➕/❌ 버튼 클릭
4. **저장**: 💾 저장 버튼 클릭

### 파일 업로드
1. **파일 준비**: `data_XXXX_YYYYDDMM.xlsx` 형식의 파일 준비
   - 예: `data_ETF_20251119.xlsx` (2025년 11월 19일)
2. **업로드**: 헤더의 📄 ETF 또는 📈 주식 버튼 클릭하여 파일 선택
3. **자동 반영**: 종목명, 종가가 자동으로 ROI 테이블에 입력됨
4. **날짜 업데이트**: Balance의 연도/월이 자동으로 업데이트됨

### 리밸런싱
1. **Portfolio 탭**: 종목코드, 자산군, 구분, 세팅비중 입력
2. **Rebalancing 버튼**: 🔄 버튼 클릭
3. **결과 확인**: 현재비중 및 빨강매수 자동 계산됨
   - 빨간색 숫자: 매수 필요
   - 괄호 숫자: 매도 필요
